Android PERMISSIONS

Storage access and Bluetooth are mandatory permissions. Without them the app will not run.
Storage
TopoDroid saves the survey data and sketches, and the calibrations, in the primary external storage.
It cannot work without read/write access to the storage.

Bluetooth
TopoDroid requires bluetooth access to communicate with the devices.
If the survey data are entered manually, it can be used without bluetooth.
TopoDroid uses also bluetooth pairing, to pair with newly discovered devices. Discovery and pairing of DistoX2 can be done with the "settings" app.
Discovery of BLE devices are done by TopoDroid itself, and it requires Location permission.

Location
Location is non-mandatory, but it is necessary to scan for BLE devices.
TopoDroid uses the device GNSS to get the geographical position of a point, but it can import it from external apps.
GNSS is used also to track a point on the DEM in the 3D viewer.

Camera
Camera permission is non-mandatory.
TopoDroid can use the camera to take pictures.
TopoDroid camera management is not so feature-rich as that of a "camera" app, but it stores the direction of view (azimuth and inclination) in the pictures.

Audio
Audio permission is non-mandatory.
TopoDroid uses the microphone to record audio notes (for shots and audio points).
If this permission is not granted, audio recording is disabled.
It should be safe to use TopoDroid without this permission.

Internet
The network connection is necessary to install a translation of the user manual.
TopoDroid uses the network access also to tranfer the function-usage counts. This is done only once a month and the amount of data transfer is very small.
