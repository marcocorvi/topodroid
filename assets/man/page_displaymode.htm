SURVEY DATA DISPLAY MODE

This dialog is opened from the display mode button in the Survey Data window.

Through this dialog the user can hide/show certain classes of shots:

  • shot id
  • splay: shots with only one station
  • scan: scan sets
  • latest splays: only available if Secondary settings > Survey data > Recent shots setting is enabled. Time limit defined by Secondary settings > Survey data > Recent data timeout setting (in seconds).
  • blank: shots with no stations
  • repeated leg: shots close to the preceding leg

The shot ids are unique increasing indices assigned by TopoDroid to the shots of the survey.

If the splay shots are hidden it is still possible to show the splay shots for individual stations. Tapping on the station name in a leg shot opens the Saved stations dialog through which the display of the splays of the specified station can be toggled on and off.
