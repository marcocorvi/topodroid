SECTION LINE

This dialog is opened when you select a point of a section-line, in editing mode of the Drawing window, and tap the Edit button.

Section lines are special as they are associated with x-sections (both sketch and photo) and can have a section-point attached.
Therefore they have different fields:

  • "section comment" (text field)
  • the photo thumbnail and info (orientation and date), if the x-section has a photo.
  • five action button:
    • take a photo
    • open the x-section sketch
    • delete the x-section
    • save the x-section comment.
    • insert a section-point. If there is already a section-point this button is not shown

Tapping the thumbnail displays the photo.

The Cancel button or the BACK key closes the dialog.
