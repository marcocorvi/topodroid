MULTI-SHOT EDIT

This dialog is opened by the "light bulb" button from the Surevy Data window in multi-shot mode.

It has the following actions

  • renumbering the shots stations. The first selected shot must be a leg
    The stations of the first shot are used to seed the renumbering. They can be changed in the dialog. If both stations are entered, the first selected shot is a leg and the following selected shots are renumbered consistently. If only the FROM station is entered (and the TO station is left empty), all the shots are renumbered as splay.
  • swapping stations
  • adding a length offset (positive or negative) to the shots (in the configured unit). An offset larger than 0.1 m marks the shots as "tampered", ie, displayed in red
  • coloring the splays [T]
    Setting the color of splays is enabled if only splays have been selected, otherwise it is disabled.
  • marking the splays as either regular (-), x-section (X), horizontal (H) or vertical (V). [T]
  • hiding the splays in either the plan, or the profile view, or both. [T]
  • computing the plane that fits the shots (only if the Plane interpolation option is enabled) [T]
    The computation of strike and dip of the bedding plane requires that all the selected shots have the same FROM station. Otherwise, it is disabled. The result is shown in the dialog and added to (replaced if already present) the comment of the first selected shot.

Splay coloring, marking, and hiding are available only if all selected shots are splays and the "splay coloring" setting is enabled.

Bedding computing is available only if the "plane fitting" setting is enabled.
