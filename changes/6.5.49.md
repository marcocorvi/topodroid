#TopoDroid v. 6.5.48 - What's new
 
*Therion parser

The Therion parser has been largely rewritten and it now supports more of the Therion synstax, although not completely.
In particular only the "data normal" mode is supported.

What's new:

1. "units" is fully supported, including clino "percent"
2. "calibrate"
3. LRUD to both FROM and TO stations
4. "cs": only WGS84 "long-lat" and "lat-long"
5. fully qualified Therion station names
6. all input value types, in particular backsight types
7. better "input" support - with encoding 
8. team collects all the name on "team" command
9. station flags are dropped
10. multiline "comment"
11. "scan" data

What's still missing:

1. data mode other than "normal" (cartesian, polar, diving, topofil and nosurvey)
2. encoding for the top import file
3. "revise" support
4. survey options "-namespace" "-person-rename"
5. computing declination from the date and the coordinates
6. "extend" with fractional part
7. '!' escaped data lines
