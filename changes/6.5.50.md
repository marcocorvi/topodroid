#TopoDroid v. 6.5.50 - What's new
 
*Survex parser

The Survex parser has been largely rewritten and it now supports more of the Survex synstax, although not completely.
In particular only the "data normal" mode is supported.

What's new:

1. "*units" is fully supported, including clino "percent"
2. "*calibrate"
3. "*cs" and "*fix": only WGS84 "long-lat" 
4. fully qualified Survex station names
5. all input value types, in particular backsight types
6. "*include" subsurvey files
7. "*team" collects all the name on "team" command
8. interleaved data
9. "passage" data, "*equate" 
10. "*begin" and "*end"

What's still missing:

1. data mode other than "normal" (cartesian, polar, diving, topofil and nosurvey)
2. computing declination from the date and the coordinates
