Contributing to TopoDroid

There are several ways you can contribute to TopoDroid:

(1) submit an issue.
(2) submit a pull request
(3) sign up as contributor and develop/maintain the code

SUBMIT AN ISSUE
If you find a problem or an error (bug) with the program you can submit an issue.
Before you submit an issue make sure to check the latest version of the program.
Describe the problem / error: describe what the program does and what it should do.
Include the ptogram version, the Android model, and the Android version.

N.B. Feature requests are not issues.

SUBMIT A PULL REQUEST
If you have an idea for a new feature or a change to an existing feature,
you can submit a pull request with the changes to the code.
Describe the new feature or the changes to the existing feature and
motivate why the pull request is useful for all the users.

N.B. a pull request that satisfies a particular need of yours is not worth to be
included in the program.

CONTRIBUTE TO THE CODE
Send an email asking to be added to the project contributors.
A contributor can change the code on the repository, directly.

The program translations are handled by contributors.
If you want to add the translation for a new language, read the instructions
in the folder int18.
